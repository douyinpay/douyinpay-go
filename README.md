抖音支付Golang语言版本SDK说明
## 1. 总体说明
本SDK包含App支付和H5支付方式的SDK

## 2. 接口

参见源码目录共分为五部分。
1. 支付：主要包含了下单，关单，根据订单号查询，根据外部单号查询四个接口，代码路径：services/pay
2. 退款：主要包含了退款，根据外部单号查询退款订单两个接口，代码路径：services/refund
3. 回调：主要包含了通知的解析接口，代码路径：services/callback
4. 账单：主要包含了账单的接口，代码路径：services/bill
5. 间连商户：主要包含了入驻申请、查询申请单、撤销申请单、查询商户、修改商户、绑定/查询应用 APPID、图片上传等接口，以及申请状态通知解析，代码路径：services/indirectmerchant

接口的使用方法可以参考每处代码下的xxx_test.go的测试用例

## 3. 回调通知处理要求

回调通知请使用 `services/callback.NewNotifyHandler` 解析。SDK 会在验签通过前校验平台回调头中的时间戳，默认允许本机时间与平台时间相差不超过 300 秒；超过窗口的通知会被拒绝处理。商户服务需要保证机器时间准确，避免因本机时间漂移导致合法通知被拒绝。

抖音支付可能对同一业务事件发起重试通知，商户回调接口应满足以下要求：

1. 业务处理成功后返回 HTTP 200 或 204，避免平台继续重试。
2. 按业务订单号、交易单号、事件类型等业务主键做幂等处理，重复通知不得重复发货、重复记账或重复推进状态。
3. 回调处理失败时不要先返回成功状态码；排查后可依赖平台重试或自行查询订单状态补偿。
